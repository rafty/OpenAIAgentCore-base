## ドキュメント更新タスク

<!--
plan.mdのドキュメント更新方針に基づき、必要なものだけを残す。
ADRは、重要な設計判断があり、plan.mdで必要と判断された場合だけ追加または更新する。

READMEやdocs配下の文書で、システム構成、コンポーネント間の関係、データフロー、
処理フロー、シーケンス、状態遷移、依存関係などを図で示す方が理解しやすい場合は、
Mermaid図の作成または更新をタスクに含める。文章だけで十分に理解できる場合は、図を追加しない。

小規模な図は対象文書の更新タスクに含める。複数の図や複雑な図で独立した確認が必要な場合は、
別のドキュメント更新タスクへ分割する。Mermaid図を追加または更新するタスクでは、図の目的、
本文との整合、Mermaid構文が正しく表示できることを完了条件に含める。
-->
