# セキュリティ標準

## IAM

IAMユーザーの常用は禁止し、業務でAWSへアクセスする場合はIAM Identity Centerを使用する。

管理者権限を付与するアカウントには多要素認証を必須とする。

IAMロールとポリシーは最小権限の原則に従って設計する。

## データ保護

本番環境のS3バケットではパブリックアクセスをすべてブロックする。

本番環境のS3、EBS、RDSの保存データはAWS KMSを使用して暗号化する。

アプリケーションのシークレットはAWS Secrets Managerに保存し、ソースコードや環境変数ファイルへ記載しない。

## セキュリティ監視

本番環境ではAmazon GuardDutyとAWS Security Hubを有効化する。

重大度がCriticalまたはHighの検出結果は、発見から1営業日以内に対応方針を決定する。
